# 腾讯云弹性公网ip要钱吗：四种计费模式价格拆解，含闲置 IP 资源费和选型建议

要钱，而且账单通常分成两笔：EIP 没有绑定云资源时产生的 IP 资源费，和绑定资源后实际产生流量、占用带宽时产生的公网网络费。前者按小时计、精确到秒，后者取决于你选哪种计费模式。

如果你问的是随云服务器一起买的那个公网 IP，情况不一样。普通公网 IP 没有 IP 资源占用费这一项，代价是不能解绑、不能独立持有。腾讯云官方文档把两者的差异列得很清楚，EIP 换来的是自由绑定与解绑，多出来的是 IP 资源费。

## 腾讯云 EIP 的账单到底由哪几部分组成？

两笔：IP 资源费和公网网络费。IP 资源费只和 EIP 的状态有关，公网网络费只和计费模式、实际用量有关，两者不重叠。

IP 资源费这部分，腾讯云申请 EIP 的文档写得很直白：按小时计费，精确到秒级，不足一小时按闲置时间占比收取。文档还建议及时给未绑定的 EIP 绑定云资源，“节省 IP 资源费”。换句话说，EIP 申请下来挂着不用，钱照走。

公网网络费在绑定云资源后才产生，四种模式可选：按流量、包月带宽、按小时带宽、共享带宽包。

官方那张对比表能看清 EIP 和普通公网 IP 的成本差别：

| 对比项 | 普通公网 IP | EIP |
| --- | --- | --- |
| 访问公网 / 被公网访问 | ✓ | ✓ |
| 独立购买与持有 | × | ✓ |
| 自由绑定与解绑 | × | ✓ |
| 实时调整带宽 | ✓ | ✓ |
| IP 资源占用费 | × | ✓ |

最后一行值得单独看一眼。同样提供公网访问能力，普通公网 IP 不收 IP 资源占用费，EIP 收。换来的能力是：EIP 可以随时与 CVM、NAT 网关、弹性网卡、高可用虚拟 IP 绑定和解绑，生命周期和云资源解耦，业务迁移时地址能跟着走。

### 包月带宽：分段累加，别被“单价”误导

包月带宽的价格是分段累加的。广州、上海、南京、北京、中卫、中国香港、新加坡这一档：

| 地域 | ≤2Mbps 部分 | 2–5Mbps 部分 | >5Mbps 部分 |
| --- | --- | --- | --- |
| 广州、上海、南京、北京、中卫、中国香港、新加坡 | 20 | 25 | 90 |
| 成都、重庆 | 18 | 22 | 80 |

单位：元/Mbps/月。

其余境外地域普遍更贵：首尔、法兰克福 20 元/Mbps/月，新山 23 元，雅加达、东京、大阪 25 元，硅谷、弗吉尼亚、克雷塔罗、曼谷、圣保罗、利雅得 30 元/Mbps/月，最后一组的高带宽档位会到 100 元。

官方计费示例算得很清楚：广州买 15Mbps、2 个月，费用是（20×2 + 25×3 + 90×10）× 2 = 2030 元。这里前 2Mbps 按 20 元算，3–5Mbps 按 25 元，剩下 10Mbps 才轮到 90 元。如果直接拿 15 乘以 90 去估预算，会高出一大截。

包月带宽是预付费，购买时可以选时长，也可以勾选自动续费，账户余额足够时到期按月续。

## 把账单算出来：包月、按小时、按流量各花多少

先看官方给的三组示例，再看一个按官方单价推算的临界点。

**包月带宽**：广州、15Mbps、2 个月，2030 元（计算过程同上）。

**按小时带宽**：中国香港、15Mbps、使用 1 小时。≤5Mbps 部分 0.08×5 = 0.4 元，>5Mbps 部分 0.25×10 = 2.5 元，合计 2.9 元。

**按流量**：广州、10GB。0.8×10 = 8 元。

真正影响选择的是下面这个测算。中国大陆 5Mbps 按小时带宽，连续跑满一个月按 730 小时算，0.063×5×730 ≈ 230 元。同样 230 元走按流量，大约能买 287GB。

也就是说，月流量低于 287GB 左右时，按流量更划算；超过这个量，固定带宽开始占优。这个数字是按官方公开单价推算的，实际账单还会受计费小时数和带宽峰值影响，但量级可以参考。

## 哪些地方最容易多花钱？

闲置的 EIP、用不上的包月带宽、选错的线路类型。三个都和实际用量无关，属于配置层面的浪费。

1. **申请了没绑定。** IP 资源费按闲置时间占比、精确到秒计。测试完的 EIP 记得释放，别留在列表里当收藏品。
2. **低频业务买包月带宽。** 包月是预付费，业务停了带宽费照付。
3. **线路类型和计费模式对不上。** 常规 BGP IP 支持按流量、包月带宽、按小时带宽、共享带宽包四种；精品 BGP IP 只支持包月带宽和共享带宽包；加速 IP、静态单线 IP、高防 EIP 目前只支持共享带宽包。想用按流量计费，线路类型只能是常规 BGP IP。
4. **多个 EIP 各自买带宽。** 公网流量高峰分布在不同时间段的业务，共享带宽包能把带宽聚合起来计费。

第三条是很多人下单时才发现的问题：计费模式受线路类型限制，选之前先确认线路支持哪种。

## 按流量计费的流量是怎么统计的？

按下行字节数统计，而且账单数字通常比你在服务器上看到的更多。腾讯云文档说明，公网流量按“腾讯云数据中心到公网”的流量字节数统计。

多出来的部分有两个来源。一是 TCP/IP 包头，每个最大 1500 字节的包里含 40 字节包头，这部分开销约 3%；二是 TCP 重传，正常传输中 3%–10% 的包会被丢弃重传，应用层统计不到，占比约 3%–7%。官方给的整体估计是：云上统计的流量可能比服务器自行统计的多 10% 左右。

按流量计费做预算时，把这个系数算进去，别按应用层日志的数字卡着预算买。

## 常见问题

**EIP 不绑定云资源要钱吗？**
要。IP 资源费按小时计，精确到秒级，不足一小时按闲置时间占比收取。

**绑定后不跑公网流量还要钱吗？**
看计费模式。按流量计费不产生流量就不产生流量费；包月带宽和按小时带宽按你购买或设置的带宽收，用不用都一样。

**普通公网 IP 有 IP 资源费吗？**
没有。官方对比表里，IP 资源占用费只有 EIP 这一列打了勾。

**一个账号能申请多少个 EIP？**
官方文档列出的默认配额是每个账户每个地域 20 个，每个地域每天申购次数为配额数×2。不够用需要提交工单调整，实际以控制台显示为准。

**EIP 能换绑到另一台服务器吗？**
可以。EIP 支持与 CVM、NAT 网关、弹性网卡、高可用虚拟 IP 绑定和解绑，这也是它比普通公网 IP 多收一笔 IP 资源费的核心原因——地址是独立资产，不跟着某台机器生老病死。

## 最后：按你的情况选一个

**只是临时测试、学习、跑个 demo**：选按流量，0.80 元/GB，测试完立刻释放 EIP，把 IP 资源费也一起掐掉。

**长期稳定、流量可预测的业务**：包月带宽。广州、上海、北京这类主力地域，前 2Mbps 只要 20 元/Mbps/月，把分段价算清楚再定带宽，别一上来就买 20Mbps。

**短期项目但峰值平稳**：按小时带宽，大陆 0.063 元/Mbps/小时起步，香港 0.08 元。

**手里有多个 EIP、流量高峰错开**：共享带宽包，具体价格按带宽包规格在控制台确认，官方没有公开统一单价。

下单前最后确认一件事：你选的线路类型支持你要的计费模式。常规 BGP IP 四种都支持，精品 BGP、加速 IP、静态单线 IP 和高防 EIP 就没这么自由了。
